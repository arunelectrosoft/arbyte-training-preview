# arbyte-training-preview

Preview the Arbyte training courses before you begin.

## Peek into Linux

Learn the foundations of working with Linux:

- Navigating the file system and using the command line
- Managing files, permissions, and processes
- Understanding shells, packages, and basic system administration

## Peek into Embedded Systems

Explore the building blocks of embedded development:

- Microcontrollers, hardware interfaces, and development tools
- C programming for resource-constrained devices
- GPIO, sensors, communication protocols, and debugging
